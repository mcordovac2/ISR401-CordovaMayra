
# Evidencias de Wattpad

Esta carpeta contiene capturas de pantalla
del sistema Wattpad utilizadas como evidencia
para el análisis de requisitos.

Las capturas serán seleccionadas y organizadas
según las funcionalidades observadas:

- Búsqueda de historias.
- Lectura de capítulos.
- Interacción mediante votos.
- Biblioteca personal.

Las imágenes se utilizan únicamente con
fines académicos.
